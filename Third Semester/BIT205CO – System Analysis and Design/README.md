# BIT205CO – System Analysis and Design

**Year II | Semester I (Third Semester) | Credits: 3**

## Teaching and Examination
Theory: 3 hrs/week | Tutorial: 1 hr/week | Practical: –  
Internal Theory: 20 | Final Theory: 80 | Total: 100

## Course Objective
Build a foundation for systems analysts and users involved in developing systems that satisfy an organization's information needs.

## Course Contents

1. **Overview of Systems Analysis and Design — 6 Hrs:** Introduction to system analysis/design; information systems and types; stakeholders; SDLC and Waterfall, Spiral, Prototype models; analysis and design tools.
2. **Process and Conceptual Modeling — 6 Hrs:** Data Flow Diagram (DFD); concepts used in drawing DFDs; DFD design up to level 2; conceptual modeling; Entity Relationship Diagrams.
3. **Logic Modeling — 3 Hrs:** Decision table; decision tree; structured English; data dictionary.
4. **Systems Analysis — 8 Hrs:** System planning and initial investigation; project scheduling; requirement analysis; types of requirements; requirement gathering methods; feasibility study and types; feasibility steps; cost/benefit analysis (Payback and NPV methods).
5. **Systems Design — 8 Hrs:** Introduction, process and stages; logical and physical design; structured design (modular design, functional strength, structure chart, cohesion, coupling); database design and file organization; normalization; input/output and forms design.
6. **System Implementation — 6 Hrs:** System implementation and installation types; system quality and software quality assurance (Formal Technical Review, walkthrough, inspections); maintenance, types and process; system testing.
7. **Object-Oriented Analysis and Design — 8 Hrs:** Object-Oriented Development Life Cycle; Unified Modeling Language; use-case modeling; class diagrams; state diagrams; sequence diagrams.
