## Group A
**Answer TWO questions.** *(2 × 12 = 24)*

1. What are the various steps in system development life cycle? What is the outcome of each step? Explain.

2. What do you mean by context diagram and top-level logical DFD? Develop a context diagram and top-level logical DFD for the system made up of the following.

   ABC is a mail-order company that distributes CDs, DVDs of music, games, movies, and software at discount prices to club members.

   - When an order processing clerk receives an order form, he or she verifies that the sender is a club member by checking the Member file.
   - If the sender is not a member, the clerk returns the order along with a membership application form.
   - If the customer is a member, the clerk verifies the order item data by checking the Item file.
   - Then the clerk enters the order data and saves it to the Daily Order file. The clerk also prints an invoice and shipping list for each order, which are forwarded to the Order Fulfillment Department.

3. What is the significance of the Entity Relationship model? Draw an ER diagram for a Company database having EMPLOYEE, DEPARTMENT, and PROJECT as entities. The company has several departments, each identified by a department number. An employee is assigned to one department, but may work on several projects that are not necessarily controlled by the same department. A project is identified by a project number. Make additional assumptions if required.
