# BIT204CO – Computer Network and Data Communication

**Year II | Semester I (Third Semester) | Credits: 3**

## Teaching and Examination
Theory: 3 hrs/week | Tutorial: 1 hr/week | Practical: 2 hrs/week  
Internal: Theory 20, Practical 50 | Final: Theory 80 | Total: 150

## Course Objective
Provide fundamental concepts of data communications and networking and their practical applications.

## Course Contents

1. **Introduction to Networking and Data Communication — 3 Hrs:** Need of data communication; data and signals; analog/digital signals; computer networks and benefits; LAN, PAN, MAN, WAN; client/server and peer-to-peer models; bus, ring, star, mesh and hybrid topologies.
2. **Layered Network Architecture — 4 Hrs:** Layered approach and benefits; OSI reference model; TCP/IP model; network protocols and TCP/IP protocol suite.
3. **Data Transmission Fundamentals & Physical Layer — 6 Hrs:** Signals; analog/digital transmission; guided/unguided media; bandwidth, channel capacity, latency, throughput and impairments; simplex, half/full duplex; circuit/packet switching; synchronous/asynchronous serial transmission; FDM, WDM, TDM; encoding and modulation; AM, FM, PM; ASK, PSK, FSK.
4. **Data Link Control — 6 Hrs:** Data link functions; flow control; Stop-and-Wait, Sliding Window, Piggybacking; parity, checksum, CRC, forward/backward error correction and Hamming code; MAC address; framing, HDLC, PPP; channel allocation and multiple access; collision/broadcast domains; FDDI, ALOHA, VLAN, IEEE 802.3 Ethernet, 802.4 Token Bus, 802.5 Token Ring, 802.11 Wireless LAN.
5. **Network Layer — 10 Hrs:** Network addressing; IPv4 and classful addressing; hub, Layer-2/Layer-3 switch, bridge, router, gateway; subnetting; adaptive/non-adaptive routing and routing table; RIP, OSPF, BGP, unicast/multicast; shortest-path, distance-vector and link-state routing; ARP, RARP, ICMP; IPv6, packet formats, dual stack and tunnelling.
6. **Transport Layer — 5 Hrs:** Functions; TCP/UDP; ports and sockets; connection establishment/release; flow control and buffering; token bucket and leaky bucket; NAT.
7. **Application Layer — 5 Hrs:** DNS, DHCP, HTTP, HTTPS; SMTP, IMAP, POP3; FTP, FTPS, SFTP; SNMP, Packet Tracer, Wireshark; proxy, reverse proxy and webmail.
8. **Network Security — 6 Hrs:** CIA model; security threats; cryptography and symmetric/asymmetric encryption; AES, RSA; digital signature and PGP; SSL/TLS; firewall, VPN and packet filtering.

## Laboratory Works
- Install NIC and network devices (hub, switch, router)
- Construct straight-through and crossover cables
- Install/configure Windows/Linux server and workstation
- Set up and verify client/server and peer-to-peer networks
- Workgroup and domain networking
- Network commands; inspect IP/MAC; configure IP and default gateway
- File/printer sharing; firewall configuration
- Configure and verify HTTP, FTP, DHCP and Telnet servers
- Configure DNS and email server
- Network management and troubleshooting
- Static and dynamic routing (RIP, OSPF)
- Data-link framing: character, character stuffing and bit stuffing
- CRC implementation; LAN design; college network case study
