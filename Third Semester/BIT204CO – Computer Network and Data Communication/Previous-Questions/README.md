## Group A
**Answer TWO questions.** *(2 × 12 = 24)*

1. What is data communication? With appropriate figures discuss about different types of guided and unguided transmission medium. **[2+10]**

2. What is and *(an)* IP Address? If we have to create 3 subnetworks from a given address of `192.168.5.0/24`. Calculate the **[2+10]**
   - **(i)** Network Address
   - **(ii)** Subnet Mask
   - **(iii)** Valid Host Range
   - **(iv)** Broadcast Address  
   of the new subnets that are created.

3. What is a parity bit? For a data bit `m(x) = 110100101101`, find the checksum value at the transmitting end of the communication. Also find the checksum value at the receiving end if there was no error during transmission. **[2+10]**
