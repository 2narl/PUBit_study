## Group A
**Answer TWO questions.** *(2 × 12 = 24)*

1. Fit an exponential curve to the following data.

   | X | 0 | 1 | 2 | 3 |
   | :--- | :---: | :---: | :---: | :---: |
   | **Y** | 1 | 1.8 | 1.3 | 2.5 |

2. What are linear equations? Explain with examples. Solve the following systems of equations by Gauss Siedel iteration method.

   [
   3x_1 + 6x_2 + x_3 = 16
   ]
   [
   2x_1 + 4x_2 + 3x_3 = 13
   ]
   [
   x_1 + 3x_2 + 2x_3 = 9
   ]

3. Find `d²y/dx²` at `x = 0.1` from the following table:

   | X | 0.0 | 1.0 | 2.0 | 3.0 | 4.0 |
   | :--- | :---: | :---: | :---: | :---: | :---: |
   | **Y** | 1.0000 | 0.9975 | 0.9900 | 0.9976 | 0.9604 |

## Group B
**Answer SEVEN questions.** *(7 × 8 = 56)*

4. What are numerical errors? Explain in details about the taxonomy of errors with necessary blocks.

5. Obtain any one of the real roots of the given equation using Bisection method:
   [
   x^3 + x^2 - 1 = 0
   ]

6. Find the root of the equation `f(x) = x² - 3x + 2` using Newton Raphson method. Use `x₁ = 0`.

7. What is interpolation? Find the Lagrange interpolation which agrees with the following data.

   | X | 1.0 | 1.1 | 1.2 |
   | :--- | :---: | :---: | :---: |
   | **Cosx** | 0.5403 | 0.4536 | 0.3624 |

   Use it to estimate `cos 1.5`.

8. Solve the system by using Gauss Jordan method.

   [
   3x_1 + 2x_2 + x_3 = 10
   ]
   [
   2x_1 + 3x_2 + 2x_3 = 14
   ]
   [
   x_1 + 2x_2 + 3x_3 = 14
   ]

9. Estimate the value of the integral
   [
   \int_{2}^{7} \frac{1}{x} \, dx
   ]
   using Simpon's *(Simpson's)* 3/8 rule. Take `h = 1`.

10. Using Euler's method, find the value of `y(0.2)` and `y(0.3)`. Given `dy/dx = 2y` and `y(0) = 1`. Take `h = 0.1`.

11. Use `4th` order Runge-Kutta method to find out the value of `y(0.6)`.  
    Given: `dy/dx = x + y`, `y(0) = 3` and `h = 0.15`.
