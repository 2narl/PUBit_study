2. Draw and explain the pin diagram of 8051 microcontroller.

3. Write an assembly language program to display your first name in a LCD module along with necessary circuit.

### 2025

**Subject:** BIT202CO: Microcontroller *(New Course)*  
**Duration:** 03:00 hrs.  
**Full Marks:** 80 | **Pass Marks:** 32

## Group A
**Answer TWO questions.** *(2 × 12 = 24)*

1. What is microcontroller? Draw and explain the pin diagram of 8051 microcontroller. **[2+10]**

2. **(a)** Write the difference between RISC and CISC **[2]**  
   **(b)** Write a C program that continuously generates a square wave of 500 microseconds period on pin P2.5. Use the timer 0, mode 2 (8 bit auto-reload) to create the delay. Assume that `XTAL = 11.0592 MHz` **[10]**

3. Draw and describe the internal architecture of 8051 microcontroller.

---

## Group B
**Answer SEVEN questions.** *(7 × 8 = 56)*

4. What is addressing mode? Describe the addressing modes of 8051 microcontroller with suitable example. **[1+7]**

5. Explain the memory structure of 8051 along with special function registers (SFRs).

6. Explain about arithmetic and logic instructions of 8051 or AUR *(AVR)* microcontroller with example.

7. Write an assembly language program for 8051 microcontroller to transfer five bytes of data from internal memory location `30h` to new internal memory location starting from `40H`.

8. Write a program to perform the followings: **[3+2+3]**
   - **(a)** Keep monitoring pin `P0.1` until it becomes high
   - **(b)** When `P0.1` becomes high, read in the data from port 1
   - **(c)** Send a low-to-high pulse on `P0.2` to indicate that the data has been read

9. Write a program in C-language OR Assembly language for 8051 microcontroller to transfer the letter `"A"` serially at 4800 baud rate continuously. Use 8 bit data, 1 stop bit.

10. What is interrupt? Explain Interrupt Enable (IE) register and hardware interrupts of 8051 microcontroller. **[1+7]**

11. Interface `16×2` character LCD with 8051. Write an assembly language program to display `"hello world"`.

12. Write short notes on **Any TWO**:
    - **(a)** ADC programming
    - **(b)** Serial communication
    - **(c)** Stepper motor
