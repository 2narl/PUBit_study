# BIT202CO – Microcontroller

**Year II | Semester I (Third Semester) | Credits: 3**

## Teaching and Examination
Theory: 3 hrs/week | Tutorial: 1 hr/week | Practical: 2 hrs/week  
Internal: Theory 20, Practical 50 | Final: Theory 80 | Total: 150

## Course Objective
Provide theoretical and practical knowledge of microcontroller, focusing on designing, implementing, and managing issues based on 8051.

## Course Contents

### Unit 1: Introduction to Microcontroller — 10 Hrs
Microcontroller basic concept; Microprocessor vs Microcontroller; Embedded Systems; Embedded Microcontrollers; 8051 Architecture (registers, pin diagram, I/O port functions); internal memory organization; external memory (ROM & RAM) interfacing.

### Unit 2: Instruction Set — 8 Hrs
Addressing modes; data transfer, arithmetic, logical, branch, and bit manipulation instructions; simple Assembly language program examples (without loops).

### Unit 3: Stack, I/O Port Interfacing and Programming — 7 Hrs
Stack and subroutine instructions; Assembly language examples on subroutines and loops; interfacing a simple switch and LED to I/O ports to switch the LED on/off according to switch status.

### Unit 4: Timers and Serial Port — 10 Hrs
Timers and counters; Assembly programming to generate a pulse using Mode-1 and a square wave using Mode-2 on a port pin; serial data communication basics; RS-232 standard and 9-pin RS232 signals; Assembly and C serial-port programs to transmit and receive data.

### Unit 5: Interrupts and Interfacing Applications — 10 Hrs
Interrupts; Assembly program for external interrupt using a switch; 8051 C program to generate a square waveform using a Timer interrupt; interfacing 8051 to ADC-0804, DAC, LCD, and Stepper motor with Assembly interfacing programs.
