# BIT101CO – Fundamentals of Information Technology

**Program:** Bachelor in Information Technology (BIT)  
**University:** Purbanchal University (PU)  
**Year:** I  
**Semester:** I  
**Course Type:** Theory

## Course Overview

Introduces computer systems, hardware and software, data representation, operating systems, databases, networks, the Internet, information security and emerging IT technologies.

## Main Topics

- Computer fundamentals, characteristics, generations and classification
- Computer organization, input/output devices and storage
- System software, application software and operating systems
- Data representation, databases and DBMS fundamentals
- Computer networks, Internet, WWW and communication protocols
- Information security, cybercrime and cyber law
- Emerging technologies and their applications
