**Program:** Bachelor in Information Technology (BIT)  
**University:** Purbanchal University (PU)  
**Year:** I

This folder contains study materials, syllabus, notes, programming examples, practical work, and previous-year question papers for **BIT154CO – Object-Oriented Programming in C++**.

## Course Information

The course introduces object-oriented programming concepts using C++. It develops an understanding of classes, objects, inheritance, polymorphism, and other C++ programming features.

## Course Contents

The following is a brief unit-wise overview. Refer to the official PU syllabus for the complete topic descriptions and prescribed teaching hours.

1. **Introduction to Object-Oriented Programming** – Procedural programming vs. OOP, characteristics and applications of object-oriented languages.
2. **C++ Programming Concepts** – C++ basics, operators, type conversion and casting, arrays, pointers, `new` and `delete`, `this` pointer, manipulators, constants and enumerations.
3. **Functions Used in C++** – Function overloading, default arguments and inline functions.
4. **Classes and Objects** – Classes, objects, access specifiers, member functions, arrays of objects, static members, friend functions and friend classes.
5. **Constructors and Destructors** – Object initialization, constructors, copy constructors and destructors.
6. **Operator Overloading** – Overloading operators and rules/restrictions.
7. **Inheritance** – Base and derived classes, types of inheritance and related concepts.
8. **Virtual Functions and Polymorphism** – Dynamic binding, virtual functions and runtime polymorphism.
9. **Templates and Exception Handling** – Function/class templates and `try`, `catch`, and `throw`.
10. **Files and Streams** – File handling, reading and writing files, and file operations.

> **Note:** This is a study overview, not a replacement for the official syllabus. Always follow the latest syllabus issued by Purbanchal University.
